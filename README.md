## Projects

### Hours Worked Data Visualizer (`index.html`)
A single-page web app that turns a week of hours worked into a bar chart,
totals, and a plain-English insight about the week's trend. The analysis is
Python, running right in the browser with Pyodide — no server, no build step.
Open `index.html` in any modern browser to try it.
